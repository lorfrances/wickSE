# wickSE
These 3 files were developed for use in the Surface Evolver (https://kenbrakke.com/evolver/evolver.html) for 3-D numerical simulations of the capillary surface and pressure in evaporating wick structures. These include:

  (1) A 3D-printed wick microstructure (unit-cell) with the meniscus facing outward on the open plane (1/6 geometry by symmetry).
  
  (2) Spherical particle (unit-cell) for use in a hexagonal packing arrangement. It is also sintered to the substrate (1/8 of the diameter is truncated in vertical direction).
  
  (3) The 3D-printed wick microstructure (1), including a central strut (1/6 geometry by symmetry).
